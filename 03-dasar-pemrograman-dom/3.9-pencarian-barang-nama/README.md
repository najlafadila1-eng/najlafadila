# Pencarian Barang Berdasarkan Nama

Program untuk mencari barang berdasarkan nama secara **case-insensitive**.

## Data Barang

- Pensil
- Buku
- Penghapus
- Penggaris
- Spidol

## Pengujian

1. Cari `pensil` → ditemukan
2. Cari `BUKU` → ditemukan
3. Cari `penghapus` → ditemukan
4. Cari `sepatu` → tidak ditemukan
